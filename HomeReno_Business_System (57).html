🌐 Hosting & Scaling — go live + hundreds of products

Why host? Right now this app runs from a file on your computer. Hosting it on a web address fixes two things at once: the client portal link goes live (clients can open it on their phones), and you can store hundreds of 3D models in cloud storage instead of cramming them into the browser.

① Just hosting
Free · ~1 hour · fixes the portal
Upload this HTML file to Netlify Drop (netlify.com/drop — literally drag & drop), Cloudflare Pages, or GitHub Pages. You get a real URL like yourbiz.netlify.app. The portal QR + email link go live automatically.
② Hosting + asset storage
~$1–5/mo · scales to hundreds
Add a storage bucket — Cloudflare R2 (cheapest, no egress fees), Backblaze B2, or AWS S3. Upload each GLB once, then in Asset Library paste the model's URL (Option B). Only the link is stored, so hundreds of products stay fast.
③ Shared backend
Later · multi-device sync
When the office, the site iPad and a laptop all need the same live data, add Supabase (free tier: database + storage + login). Bigger job — worth it once you outgrow single-device use.

Recommended first step: do ① now (drag this file onto Netlify Drop). Your portal links work immediately. Then do ② when you have GLB models from suppliers. The app is already built to support both — nothing more to install.

Note: cloud-hosted model URLs must allow cross-origin access (CORS). R2/S3/B2 all let you enable this with one setting — search "[your storage] enable CORS".
